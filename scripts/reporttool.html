PC Component Report Tool

This script is the first script i have made in Powershell. I orginally built this script to help a friend remotely identify the components in their gaming PC. Said friend had not touched the PC in so long that they no longer knew what was in the machine, nor what to upgrade to improve performance.

It's a simple and short script that gathers information about the host machine's components and the details regarding those components. The results are parsed to a .txt file, which is then saved to the machine's desktop. Which allows for simple and fast reviewing and sharing.

 

    # Set output path
  $outputPath = "$env:USERPROFILE\Desktop\PCReport.txt"
  
  # Start the report
  "PC Information Report - Generated on $(Get-Date)" | Out-File -FilePath $outputPath
  "==============================================" | Out-File -Append $outputPath
  
  # Basic system info
  "--- System Info ---" | Out-File -Append $outputPath
  Get-ComputerInfo | Select-Object CsManufacturer, CsModel, CsSystemType, CsTotalPhysicalMemory, CsNumberOfLogicalProcessors, OsName, OsVersion, OsInstallDate, BiosManufacturer, BiosBIOSVersion | Format-List | Out-File -Append $outputPath
  
  # Physical disks info (drive type, health, size)
  "`n--- Physical Disk Info ---" | Out-File -Append $outputPath
  Get-PhysicalDisk | Select-Object DeviceID, MediaType, Size, SerialNumber, HealthStatus | Format-Table -AutoSize | Out-File -Append $outputPath
  
  # Drive model and interface type
  "`n--- Disk Models and Interfaces ---" | Out-File -Append $outputPath
  Get-WmiObject Win32_DiskDrive | Select-Object Model, InterfaceType, MediaType, Size | Format-Table -AutoSize | Out-File -Append $outputPath
  
  # SMART Failure Prediction
  "`n--- SMART Failure Prediction ---" | Out-File -Append $outputPath
  Get-WmiObject MSStorageDriver_FailurePredictStatus | Select-Object InstanceName, PredictFailure | Format-Table -AutoSize | Out-File -Append $outputPath
  
  # Final note
  "`nReport saved to: $outputPath" | Out-File -Append $outputPath
