PC component report utility

This is a small PowerShell script I wrote to make it easier to collect the basic hardware and Windows information from a PC and put it into a simple text report.

Why I made it

I originally needed a quick way to identify the parts and system details of a remote Windows PC when the owner did not have an accurate hardware inventory.

What it does

The script uses PowerShell with CIM/WMI data sources to collect system, CPU, memory, storage, and Windows information. It then writes the results to a text file on the user's desktop so the report can be sent back or kept with the machine's notes.

Why it is still here

It is not a major security tool, and I do not want to pretend it is. I keep it in the portfolio because it is a simple example of how I use scripting: take a repetitive support task, collect the information automatically, and produce something useful at the end.
